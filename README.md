# SMASH RECORD — スマブラSP 戦績トラッカー

大乱闘スマッシュブラザーズ SPECIAL の勝敗を記録・分析できる、ビルド不要の Web アプリです。
データはブラウザの **localStorage** に保存されるため、サーバーもアカウントも必要ありません。

## 使い方

`index.html` をブラウザで開くだけで動作します。

- ローカル: ファイルをダウンロードして `index.html` をダブルクリック
- GitHub Pages: リポジトリの Settings → Pages で `main` ブランチのルートを公開すると、そのまま Web アプリとして使えます

## 機能

| タブ | 内容 |
| --- | --- |
| 記録 | 自分のキャラ / 相手のキャラ / 勝敗 / メモ（任意）を入力して保存。累計の対戦数・勝敗・勝率を常時表示 |
| 履歴 | 過去の対戦を新しい順に一覧表示。相手キャラでの絞り込み、1件ずつの削除、JSON の書き出し / 読み込み、全削除 |
| 分析 | 相手キャラ別の対戦数・勝利数・勝率(%) をランキング表示（勝率順 / 対戦数順 / 勝利数順 / 苦手順）。自分のキャラでの絞り込みと、自キャラ別の戦績も表示 |

- 参戦ファイターは全 86 種（ダッシュファイター・Mii ファイター 3 種を含む）を収録しています。
- キャラクター選択はアイコン付きのグリッドから行えます（キャラ名・シリーズ名・slug で検索可能）。
  履歴や分析画面でもキャラ名の横にアイコンを表示します。
- ダーク基調のデザインで、スマートフォン画面に最適化したレスポンシブレイアウトです。

## ファイル構成

```
index.html          画面のマークアップ
styles.css          スタイル（ダークテーマ / レスポンシブ）
characters.js       ファイター一覧・シリーズ定義・アイコン設定
app.js              記録・保存・集計・キャラ選択ロジック
assets/icons/       キャラアイコン画像の配置先（既定では空）
```

外部ライブラリやビルド手順は一切不要です。

## キャラアイコンについて

既定では画像を同梱せず、**シリーズカラー＋頭文字のアバター**を表示します。
オフラインでも必ず表示され、外部サービスへの依存もありません。

実際のキャラ画像を使う場合は、次のどちらかを設定してください。

1. `assets/icons/` に `<slug>.png`（例: `mario.png`, `cloud.png`）を置く
2. `characters.js` 冒頭の `ICON_BASE` を任意の URL テンプレートに変更する
   ```js
   var ICON_BASE = 'https://example.com/ssbu-icons/{slug}.png';
   ```

slug は `characters.js` の各ファイターに定義されています。詳細は
[`assets/icons/README.md`](assets/icons/README.md) を参照してください。

フォールバックは二段構えです。

- 起動時に 1 枚だけ試験読み込みし、取得できない環境ではそれ以上リクエストを出さず
  アバター表示に切り替えます（画像未配置時、コンソールに 404 が 1 件だけ出ます）。
- 個別の画像が欠けている場合も、そのキャラだけアバター表示に切り替わります。

なお、ゲーム内のファイターアートワークは任天堂および各権利者の著作物のため、
このリポジトリには画像を同梱していません。

## データについて

- 保存先はブラウザごとの localStorage（キー: `smash-record/battles/v1`）です。
- 別の端末やブラウザとは同期されません。バックアップや移行には「履歴」タブの JSON 書き出し / 読み込みをご利用ください。
- ブラウザのサイトデータを削除すると記録も消えます。
