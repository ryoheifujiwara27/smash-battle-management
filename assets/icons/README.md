# キャラアイコン画像の配置

このディレクトリに `<slug>.png` という名前で画像を置くと、キャラクター選択・対戦履歴・
分析画面のアイコンとして自動的に使用されます（推奨サイズ: 128×128 前後の正方形）。

slug は `characters.js` の各ファイターに定義されています。

```
assets/icons/mario.png
assets/icons/donkey_kong.png
assets/icons/cloud.png
...
```

## 外部URLを参照する場合

`characters.js` 冒頭の `ICON_BASE` を書き換えてください。`{slug}` が各ファイターの
slug に置換されます。

```js
var ICON_BASE = 'https://example.com/ssbu-icons/{slug}.png';
```

## フォールバックについて

- 起動時に 1 枚だけ試験読み込みを行い、画像が取得できない環境ではリクエストを発生させず、
  シリーズカラー＋頭文字のアバターを表示します。
- 個別の画像だけが欠けている場合も、そのキャラのみアバター表示に切り替わります。
- `ICON_BASE` を `''` にすると、常にアバターのみを使用します。
